## Analysis Questions

1. **Which cloud provider offers the broadest range of services?**
   -  AWS has this broad , and honestly really mature, portfolio of cloud services worldwide, and it tends to handle the widest range of edge-case style workloads plus integrations without much fuss.
     
2. **Which provider best integrates with Microsoft technologies?**
   - Microsoft Azure feels more native with Windows Server, Active Directory , and Microsoft 365, so if you already live in a Microsoft environment, it can be the most seamless option.
     
3. **Which provider is strongest in Artificial Intelligence and Kubernetes?**
   - Google Cloud Platform , or GCP, is especially strong with AI, machine learning and Kubernetes. Like, Google originally created Kubernetes, and they also bring in pretty advanced AI development platforms such as Vertex AI.

4. **Which cloud platform would you personally choose and why?**
   - I’d pick AWS because of the huge community ecosystem, very extensive documentation , and that industry standard adoption. In practice this usually makes troubleshooting easier, and resource management feels more efficient overall.
