## Brief Overview
Microsoft Azure is a public cloud computing platform providing services including compute, analytics, storage, and networking, tightly integrated with Microsoft’s enterprise stack.

## Global Infrastructure
Azure has a vast geographical footprint with more global regions than many other cloud providers, ensuring compliance and local data sovereignty.

## Cloud Management Console
The Azure Portal offers an intuitive dashboard-driven workspace to manage resources, monitor health, and manage subscriptions.

## Four (4) Core Services
- **Azure Virtual Machines:** On-demand, scalable computing resources.
- **Azure Blob Storage:** Massively scalable object storage for unstructured data.
- **Azure Virtual Network (VNet):** Secure private network in Azure.
- **Microsoft Entra ID (formerly Azure AD):** Cloud-based identity and access management.

## Three (3) Advantages
- Seamless integration with Windows Server, Active Directory, and Office 365.
- Strong enterprise hybrid cloud capabilities.
- Flexible licensing discounts for existing Microsoft enterprise customers.

## Enterprise Use Cases
- Enterprise Windows infrastructure cloud migration.
- Hybrid cloud deployments.
- Enterprise application hosting.
