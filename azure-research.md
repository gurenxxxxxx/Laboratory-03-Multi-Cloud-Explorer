## Brief Overview
Microsoft Azure is this public cloud computing platform that gives services like compute, analytics, storage, and networking. It’s tightly linked with Microsoft’s enterprise stack, so it feels pretty natural if you already use their products.

## Global Infrastructure
Azure also has a huge geographical footprint, with more global regions than a bunch of other cloud providers, which helps with compliance and local data sovereignty stuff, even when you have stricter requirements.

## Cloud Management Console
In the day to day, the Azure Portal gives you a kind of dashboard driven workspace, where you can manage resources, check health status, and handle subscriptions without too much friction.

## Four (4) Core Services
- **Azure Virtual Machines:** on demand scalable compute, you spin them up when needed.
- **Azure Blob Storage:** extremely scalable object storage for unstructured data, pretty common for backups and documents.
- **Azure Virtual Network (VNet):** a secure private network inside Azure, with segmentation options.
- **Microsoft Entra ID (formerly Azure AD):** cloud based identity and access management, for sign in and permissions.

## Three (3) Advantages
- Seamless integration with Windows Server, Active Directory and Office 365 it just feels smooth.
- Strong enterprise hybrid cloud capabilities.
- Flexible licensing discounts for existing Microsoft enterprise customers.

## Typical Enterprise Use Cases
- Enterprise Windows infrastructure cloud migration.
- Hybrid cloud deployments.
- Enterprise application hosting.
